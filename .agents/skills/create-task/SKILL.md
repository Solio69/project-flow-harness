# 📝 Создать задачу

Опирайся на [общие правила](../../../AGENTS.md). Результат навыка - файл задачи в нужном проекте. Если пользователь выбрал задачу в работу, результат также включает согласованные задачи для человека в «Текущих действиях».

## 📥 Сохрани задачу

1. Определи проект и открой его главную заметку. Проверь очередь и рабочие файлы в `inbox/`. Если задача уже заведена, используй её файл.
2. Уточни значимые неизвестные. Сохрани в файле в `inbox/` формулировку задачи, ожидаемый результат и известные ограничения. Добавь ссылки на материалы, если они есть. Используй согласованный формат очереди, когда добавляешь в неё ссылку.
3. Проверь расположение файла и ссылки. Покажи пользователю, где находится задача.

## 🎯 Когда задача выбрана в работу

- Помоги разделить объёмную работу на выполнимые задачи. Предложи, какую часть можешь взять на себя, и согласуй с человеком, что остаётся ему и сколько времени это займёт.
- Используй исходный файл, если он уже описывает выполнимую задачу. Если подготовлены отдельные файлы задач, свяжи их с исходным. Сохрани в них договорённости о работе агента.
- Добавь в `projects/Текущие действия.md` согласованные задачи для человека и оценку его времени по правилам из `AGENTS.md`. Проверь ссылки на главную заметку и файлы задач.
