# Project Flow Harness

> 📜 **[Манифест Project Flow Harness](MANIFEST.md)**  
> Принципы совместной работы человека и агента.

## 🧭 Метод

Фреймворк помогает направить внимание на работу, которую вы можете сделать сейчас. Назовите желаемый результат и доступное время фокуса. Агент поможет разбить большую работу на выполнимые задачи и предложит, что может подготовить или сделать сам. Вместе вы оцените, сколько времени потребуется именно от вас.

> 🎯 **[«Текущие действия»](projects/Текущие%20действия.md) - ваш общий список дел.** Здесь собраны выбранные вами задачи по всем проектам. По каждой видно, что предстоит сделать вам и сколько времени на это понадобится.

С одним оркестратором можно вести несколько проектов. При переключении агент открывает главную заметку и материалы выбранного проекта. Согласованные решения и результаты сохраняются в файлах, поэтому к ним можно вернуться в следующем разговоре.

## 🗂️ Что где находится

### 🌳 Схема системных папок фреймворка

```text
project-flow-harness/
├── README.md                  # инструкция для человека
├── MANIFEST.md                # принципы совместной работы
├── AGENTS.md                  # общие правила оркестратора
├── .agents/                   # настройки и навыки агента
│   └── skills/                # общие навыки для всех проектов
│       ├── create-project/    # создаёт проект и раздел в списке дел
│       ├── create-task/       # оформляет файл задачи в проекте
│       └── archive-project/   # возвращает задачи в очередь и архивирует проект
├── archive/                   # архив целых проектов
└── projects/                  # рабочая область проектов
    ├── Текущие действия.md    # общий список задач человека
    └── Пример проекта/        # папка с главной заметкой и материалами проекта
        ├── docs/              # действующие документы и принятые решения
        ├── work/              # черновики и новые документы
        ├── files/             # исходные материалы и вложения
        ├── inbox/             # идеи и незавершённые задачи
        └── archive/           # завершённые задачи и архивные материалы проекта
```

### 📌 Главная заметка проекта

Каждый проект занимает отдельную папку в `projects/`. Рекомендуем назвать папку и главную заметку именем проекта. Например, для проекта «Пример проекта» путь к главной заметке будет `projects/Пример проекта/Пример проекта.md`. В ней кратко опишите, для чего нужен проект, и соберите задачи и ссылки на важные материалы. По этой заметке и вы, и агент сможете быстро восстановить контекст.

### 🔗 Как связаны проекты и файл «Текущие действия»

В `projects/` у каждого проекта своё рабочее место. Главная заметка объясняет, о чём проект, и ведёт к его основным документам. Структура папок помогает вам и агенту сразу понимать, где создать черновик, где лежит действующий документ и куда сохранить материалы. Общие правила агента описаны в [AGENTS.md](AGENTS.md), а настройки отдельного проекта, если они есть, лежат в его `.agents/`.

[«Текущие действия»](projects/Текущие%20действия.md) - центр фреймворка и ваш личный планировщик. Сюда из всех проектов попадают согласованные задачи, которые предстоит выполнить вам. Из списка можно открыть главную заметку проекта или файл задачи с материалами и договорённостью о работе агента. Оценка времени помогает сравнить задачи и выбрать ту, на которую сейчас хватит внимания.

### 📎 Где искать материалы проекта

В каждой подпапке проекта-примера есть удаляемая заметка с пояснением и образцом файла.

| Что вы ищете | Где это лежит |
| --- | --- |
| 💡 Идею или файл незавершённой задачи | В `inbox/`. |
| ✍️ Новый документ, который готовит агент | В `work/`. Здесь агент начинает работу над документами. |
| 📘 Принятый документ или согласованное описание | В `docs/`. Вы переносите сюда документ из `work/` вручную, когда готовы его принять. |
| 📎 Исходник, вложение или другой файл проекта | В `files/`. |
| 🗄️ Завершённую задачу или архивный материал | В `archive/`. |

## 🚀 Первый запуск

### ⚙️ Что понадобится

- Локальная папка с файлами предустановки.
- Obsidian Desktop для просмотра и редактирования заметок.
- Codex с доступом к той же локальной папке.
- [Show Hidden Files](https://community.obsidian.md/plugins/show-hidden-files), если хотите видеть папку `.agents/` в проводнике Obsidian. Плагин устанавливается и включается в настройках сторонних плагинов.

### 🖥️ Как открыть систему

1. Откройте папку предустановки в Obsidian как хранилище. В её корне находятся `AGENTS.md` и папка `projects/`. В `projects/` лежат «Текущие действия» и папки проектов.
2. Откройте ту же папку в Codex и начните чат из её корня. Оркестратор опирается на общие правила в [AGENTS.md](AGENTS.md).
3. Откройте «Текущие действия» в Obsidian и перейдите из раздела «Пример проекта» в его главную заметку. В ней собраны ссылки на образцы в папках.

## ✅ Как начать

1. Назовите проект и результат, к которому хотите прийти. Для нового проекта достаточно названия и короткого описания цели. Оркестратор поможет подготовить его структуру. Для существующего проекта он начнёт с главной заметки.
2. Скажите, на какой период выбираете работу и сколько времени фокуса у вас есть, если это уже известно. Это поможет выбрать подходящий объём.
3. Обсудите предложенные задачи и то, какую часть работы агент может взять на себя. Например, он готовит черновик плана, а вы оцениваете, сколько времени вам нужно на его проверку.
4. Подтвердите, какие задачи берёте. Агент сохранит материалы и договорённости в файлах проекта и добавит ваши задачи со ссылками в «Текущие действия».
5. После выполнения сообщите, что получилось. Вместе с агентом зафиксируйте результат в файле задачи и решите, что делать дальше.

Раз в неделю полезно сверять проекты с агентом и выбирать задачи на ближайшую неделю. Для планирования дня откройте «Текущие действия» и выберите задачи, которые помещаются в доступное время.

## 🤝 Как помогает агент

- Подключает контекст нужного проекта и читает материалы, относящиеся к задаче.
- Задаёт вопросы, когда не хватает важных сведений. Помогает сравнить варианты, разделить объёмную работу на выполнимые задачи и подготовить материалы.
- Готовит новые документы в `work/`. Вы проверяете результат и вручную переносите принятый документ в `docs/`. Агент поддерживает его актуальность и обновляет по месту.
- Замечает повторяющиеся действия и предлагает настройки, которые могут упростить работу.

### 🧩 Готовые навыки

Можно попросить агента обычными словами. Для повторяющихся операций в предустановке есть готовые процедуры.

| Навык | Пример обращения |
| --- | --- |
| 📁 [Создать проект](.agents/skills/create-project/SKILL.md) | «Создай проект [название] и подготовь его папки» |
| 📝 [Создать задачу](.agents/skills/create-task/SKILL.md) | «Создай в проекте [название] задачу [что нужно сделать]» |
| 🗄️ [Архивировать проект](.agents/skills/archive-project/SKILL.md) | «Архивируй проект [название] и верни его текущие задачи в очередь» |

По умолчанию агент добавляет раздел нового проекта в конец «Текущих действий». Под ним будут появляться выбранные вами задачи. При архивировании агент возвращает задачи из этого раздела в очередь проекта, переносит папку целиком в корневой `archive/` и убирает раздел из общего списка.

## 💬 С чем можно обратиться к агенту

- «Хочу создать проект [название]. Помоги кратко описать, зачем он нужен, и подготовить его структуру».
- «В проекте [название] хочу [результат]. Помоги разбить задачу и выбрать, что сделать первым».
- «Посмотри мои текущие действия по проекту [название]. У меня есть час, помоги выбрать подходящую задачу».
- «Подготовь черновик [документа] для проекта [название]. Давай сначала обсудим, что должно в нём быть».
